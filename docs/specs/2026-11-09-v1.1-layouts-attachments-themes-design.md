## 需求与决策

| 需求 | 决策 |
| --- | --- |
| 显示模式切换 | 6 种：思维导图（平衡）、逻辑图（向右）、组织结构图（向下）、树状图、时间轴（水平）、鱼骨图（头向右） |

## 文件格式（向后兼容）

- `<map version="1.0.1" layout="org-down" theme="dark">`：自定义属性，FreeMind/Freeplane 忽略；缺省 = `map-balance` + `default`
- 节点附件：`ATTACHMENTS` 属性 = base64(UTF-8 JSON `[{name, rel}]`)；解析失败时忽略
- 保存 payload 扩展：`save_map(path, {root, layout, theme})`

## 布局系统（layout.js）

统一接口：`computeLayout(root, sizes, mode)` → `{pos, sides, decor}`。`sides` 改为方向字符串（right/left/top/bottom），决定折叠徽章位置与连线方向。

- **map-balance / map-right**：现有水平树逻辑，后者一级全部向右；h-bezier 连线
- **org-down**：垂直树，父居中于子行上方；elbow 连线；徽章在下
- **tree-right**：先序行缩进（x = 深度×缩进）；elbow 连线；徽章在右
- **timeline**：根在左，一级节点沿水平轴向右排列，其全部后代按先序缩进堆叠在轴上/下（按索引交替）；v-bezier 连线；轴线装饰
- **fishbone**：根在右端轴头，脊线向左延伸；一级分支为上下交替斜刺，骨长随子节点列高；子节点列在骨线左侧水平肋线连接；深度 ≥4 并入父列追加缩进；脊线/骨/肋连线，骨色取一级调色板

## 主题（render/app）

`THEMES`：{canvas, dot, rootBg, rootFg, nodeBg, nodeFg, nodeBorder, edge, l1[8]}。应用规则：节点显式 bg/color（文件中的 COLOR/BACKGROUND_COLOR）> 主题默认；一级连线取 `l1` 调色板，深层连线取 `edge`；画布底色+点阵同步切换。主题/布局切换标记 modified 但不入撤销栈。

## 附件（Python + JS）

- Python：`add_attachment(map_path, src)`（复制+重名自动加序号，返回 {name, rel}）、`open_attachment(map_path, rel)`（os.startfile，不存在返回 ok:false）
- JS：侧栏「附件」区（选中节点时）：插入按钮（Ctrl+I）、列表（点击打开、× 移除引用不删文件）；未保存导图先提示保存；`node.attach` 进入 cleanTree/撤销快照

## 快捷键弹窗

`#help-modal` 复用 modal 样式：分组表格（导航/编辑/文件/视图/附件）。入口：工具栏按钮、F1；Esc/×/点击遮罩关闭。
